Open Red Software is a software company headquartered in Canada. We start and contribute to open source projects, and we take contract work on open source and proprietary software. The contract work pays for the open source work. You may also see the name written as OpenRedSoftware, which is our GitHub organization: https://github.com/OpenRedSoftware

## What we believe

- **Open source lasts.** When closed source software dies, the work that went into it goes with it.
- **Derived work stays open.** Our open source projects use copyleft licenses, the GPL and AGPL, so modified versions that are shared must stay open source under the same license.
- **Contract work funds the rest.** Open Red Software uses all of its funds to contribute to open source projects.

## Projects we founded

- **2009scape** is a free and open source remake of 2009-era RuneScape, licensed under the AGPL-3.0. Website: https://2009scape.org/ . Source: https://gitlab.com/2009scape/2009scape
- **MoneroTipsBot** lets Reddit users tip each other in Monero. It is GPL-3.0 licensed and part of the Monero Ecosystem project. Source: https://github.com/monero-ecosystem/MoneroTipper
- **OurKorean** teaches Korean through the media you already like: https://ourkorean.com/
- **xmr-donate** helps you choose a project to donate Monero to. Source: https://github.com/dginovker/xmr-donate
- **Strawpoll.lol** is an open source alternative to Strawpoll.me, licensed under the AGPL-3.0. Source: https://github.com/OpenRedSoftware/Strawpoll.lol

## Projects we contribute to
